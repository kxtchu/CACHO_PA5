Problem B2: Cramer's Rule
- I solved the same system again using Cramer's Rule. This method calculates each unknown by replacing one column of the coefficient matrix with the constants in b, finding the determinant of the modified matrix, and dividing that determinant by detA. The formula is x_j = det(A_j)/det(A), where A_j is the matrix with column j replaced by b.
- I started with x_cramer = zeros(4,1) to make a column vector that would hold the four answers. Then I used for j = 1:4 so MATLAB could repeat the same steps for all four unknowns. Inside the loop, A_replaced = A makes a fresh copy of the original matrix. The line A_replaced(:, j) = b replaces every row of column j with the values from b; the colon (:) means all rows. Next, det(A_replaced) calculates the new determinant, and x_cramer(j) = det_replaced / detA calculates the corresponding variable. I used fprintf() to show the determinant and solution for each iteration, making it easier to follow how the loop works.
- Cramer's Rule produces the same solution as the inverse method: x1 = 2, x2 = -1, x3 = 3, and x4 = 1. Using the loop was helpful because I did not have to write four separate sets of instructions for replacing columns. It also showed me how indexing can make repeated matrix calculations shorter and more organized.
